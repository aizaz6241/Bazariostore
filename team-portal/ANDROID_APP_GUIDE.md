# 📱 Bazario Team Android App & Push Notifications Guide

یہ گائیڈ آپ کو اور آپ کی ٹیم کو بتاتی ہے کہ **Bazario Team Portal** کو اپنے اینڈرائیڈ موبائل میں بطور فل ایپلیکیشن کیسے انسٹال کرنا ہے، اور **پش نوٹیفیکیشنز مع پراپر ساؤنڈ (Sound & Vibration)** کیسے کام کرتے ہیں۔

---

## 🚀 دو طریقے (Two Ways to Install on Android)

### طریقہ 1: کروم سے انسٹال (WebAPK PWA) — سب سے تیز اور بہترین طریقہ (Zero Build Required)
یہ وہی طریقہ ہے جو آپ نے پہلے آزمایا تھا، لیکن اب اس میں **فل بیک گراؤنڈ پش نوٹیفیکیشنز**، **کسٹم ساؤنڈز** اور **وائبریشن** شامل کر دی گئی ہیں:

1. موبائل میں گوگل کروم کھولیں اور پورٹل کا لنک کھولیں (مثلاً `https://your-domain.vercel.app/login`)۔
2. اوپر دائیں کونے میں **3 ڈاٹس (Three Dots)** پر کلک کریں۔
3. **"Install app"** یا **"Add to Home screen"** پر کلک کریں۔
4. چند سیکنڈ میں اینڈرائیڈ اس کو بطور اصلی ایپ انسٹال کر لے گا (جس کا الگ سے آئیکون آپ کے موبائل کی ہوم اسکرین اور ایپ ڈراور میں آ جائے گا)۔
5. ایپ اوپن کر کے لاگ ان کریں۔ اسکرین کے اوپر یا نیویگیشن بار میں **🔔 "Enable Notifications"** کا بٹن آئے گا۔ اس پر ایک بار کلک کر کے **"Allow"** کر دیں۔
6. بس! اب موبائل بند ہو، اسکرین لاک ہو یا ایپ بند ہو — جب بھی نیا میسج یا رقم/ڈپازٹ آئے گا، فون پر **پش نوٹیفیکیشن اور ساؤنڈ ٹون** فوراً بجے گی!

---

### طریقہ 2: ریپڈ اینڈرائیڈ اے پی کے (`BazarioTeam.apk`)
اگر آپ اپنے ٹیم ممبرز کو ڈائریکٹ واٹس ایپ پر ایک فائل بھیجنا چاہتے ہیں جو وہ انسٹال کر سکیں:

ہم نے پروجیکٹ کے اندر پورا اینڈرائیڈ اسٹوڈیو اسٹرکچر تیار کر دیا ہے:
📁 **`android-app/`**

اس سے APK بنانے کے آسان طریقے:

#### آپشن A: بذریعہ GitHub Actions (خودکار - بغیر کسی سافٹ ویئر کے)
1. یہ کوڈ اپنے GitHub ریپو میں پش کریں۔
2. GitHub پر جاکر **Actions** ٹیب پر کلک کریں۔
3. **"Build Bazario Team Android APK"** ایکشن پر کلک کر کے **Run workflow** دبائیں۔
4. 2 سے 3 منٹ میں GitHub خود ہی `app-debug.apk` بنا کر ڈاؤن لوڈ کے لیے دے دے گا۔ آپ وہ فائل ڈاؤن لوڈ کر کے اپنے ممبرز کو واٹس ایپ کر سکتے ہیں!

#### آپشن B: بذریعہ PWABuilder (آن لائن مفت ٹول - صرف 1 منٹ)
1. ویب سائٹ [PWABuilder.com](https://www.pwabuilder.com) پر جائیں۔
2. اپنے لائیو پورٹل کا URL درج کریں۔
3. **"Package for Android"** بٹن پر کلک کریں۔
4. یہ آپ کو فوراً سائنڈ `BazarioTeam.apk` ڈاؤن لوڈ کر کے دے دے گا!

#### آپشن C: بذریعہ Android Studio
1. Android Studio کھولیں اور `android-app` فولڈر کو اوپن کریں۔
2. `Config.java` میں اپنا لائیو Vercel URL چیک کریں۔
3. **Build > Build Bundle(s) / APK(s) > Build APK(s)** پر کلک کریں۔

## 🔔 پش نوٹیفیکیشن اور ساؤنڈ کی خصوصیات (Features Implemented)

1. **چیٹ پیغامات (Chat Messages)**:
   - جب کوئی گروپ یا پرسنل چیٹ میں میسج بھیجے گا تو وصول کرنے والے کے موبائل پر پش نوٹیفیکیشن آئے گا:
     * میسج کا متن یا "📷 Sent a photo" / "🎤 Sent a voice message"
     * واٹس ایپ طرز کی خوشگوار میسج رنگ ٹون (`/sounds/message.wav`)
     * فون وائبریشن

2. **ڈپازٹ اور رقوم کی اپڈیٹ (Deposits & Amounts)**:
   - جب ایڈمن کسی سیلر کا ڈپازٹ ریکارڈ کرے گا، تو متعلقہ ممبر کو نوٹیفیکیشن جائے گا:
     * "💰 Deposit Alert: Rs [Amount] PKR recorded for your seller"
     * کیش رجسٹر/کوائنز کی ٹون (`/sounds/cash.wav`)

3. **انعامات اور بونس (Bonus Approved)**:
   - جب ایڈمن کسی کلیم کو اپروو کرے گا یا پرفارمنس بونس دے گا:
     * "🎉 Bonus Approved! Rs [Amount] PKR credited to your wallet"
     * کیش ساؤنڈ (`/sounds/cash.wav`)

4. **سیلر تفویض (Seller Assignment)**:
   - جب ممبر کو نیا سیلر اسائن ہوگا تو الرٹ اور ساؤنڈ ٹون پلے ہوگی۔

5. **ٹیسٹ نوٹیفیکیشن بٹن (Instant Test in Navbar)**:
   - لاگ ان کرنے کے بعد اوپر نیویگیشن بار میں گھنٹی (🔔) کے آئیکون پر کلک کریں۔
   - وہاں آپ کو دو بٹن ملیں گے:
     * `💬 Test Chat`: میسج ساؤنڈ اور پش نوٹیفیکیشن چیک کرنے کے لیے۔
     * `💰 Test Money`: کیش ساؤنڈ اور ڈپازٹ الرٹ چیک کرنے کے لیے۔
   - ساؤنڈ کو آن یا آف کرنے کے لیے ایک کلک کا ٹوگل بھی موجود ہے۔
